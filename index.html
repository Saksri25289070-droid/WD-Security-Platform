ขั้นตอนการใช้งาน
1
ล็อกอินเข้าระบบ
เข้าสู่ระบบด้วย Account
ใช้ Email และ Password ที่ได้รับจาก Admin เพื่อ Login เข้าสู่ระบบ หากยังไม่มี Account กรุณาติดต่อ Admin | Kunakorn
2
ดูภาพรวมอุปกรณ์
ตรวจสอบสถานะอุปกรณ์
หน้า "ภาพรวมการตรวจอุปกรณ์" แสดงสถานะ Real-time ของประตูฉุกเฉินและวิทยุสื่อสารทั้งหมด กดปุ่ม "รีเฟรช" เพื่ออัปเดตข้อมูลล่าสุด
3
เปิด Web App ตรวจสอบ
กดปุ่ม "เปิด App" สีน้ำเงิน
ไปที่เมนู "Web App ตรวจอุปกรณ์" → เลือก App ที่ต้องการ → กดปุ่ม "เปิด App" (ปุ่มสีน้ำเงิน ในกรอบ) เพื่อเปิดแอปตรวจสอบในหน้าต่างใหม่
4
บันทึกผลการตรวจสอบ
บันทึกผลใน Web App
ทำการตรวจสอบและบันทึกผลผ่านแอปที่ตรวจ ข้อมูลการตรวจจะแสดงผลที่ห้อง Control Room ทันที
คำถามที่พบบ่อย (FAQ)
ถ้าลืม Password ต้องทำอย่างไร?
ติดต่อ Admin หรือ Super Admin เพื่อทำการ Reset Password ให้ใหม่ ไม่สามารถ Reset เองได้ผ่านระบบ
ไม่เห็นเมนู Equipment Report ต้องทำอย่างไร?
เมนูจะแสดงเฉพาะเมื่อ Admin เปิดสิทธิ์ให้คุณเท่านั้น ติดต่อ Admin เพื่อขอเปิดสิทธิ์การเข้าถึง Web App ที่ต้องการ
ข้อมูลบน Dashboard ไม่อัปเดต ต้องทำอย่างไร?
กดปุ่ม "รีเฟรช" ที่มุมขวาบนของแต่ละหน้า หรือกดปุ่ม "รีเฟรชข้อมูล" ที่หน้าภาพรวมอุปกรณ์ หากยังไม่อัปเดต ให้ refresh หน้าเบราว์เซอร์
สามารถเข้าระบบจากมือถือได้ไหม?
ได้ครับ ระบบรองรับทุกอุปกรณ์ — Desktop, Tablet, และ Mobile ทุกรุ่น ใช้เบราว์เซอร์ Chrome หรือ Safari เพื่อประสบการณ์ที่ดีที่สุด
ข้อมูลที่บันทึกจะอยู่ในระบบนานแค่ไหน?
ข้อมูลทั้งหมดจากการตรวจสอบ จะถูกตรวจสอบโดย Admin ผู้ดูแลระบบโดยทันที เพื่อรายงานผลต่อ WD Staff และสามารถดูย้อนหลังการตรวจได้ผ่านเมนู Dashboard
ติดต่อ Admin / ขอความช่วยเหลือ
หากพบปัญหาการใช้งาน หรือต้องการขอสิทธิ์เพิ่มเติม ติดต่อ Admin ของทีม REO Security (Mfg) โดยตรง
